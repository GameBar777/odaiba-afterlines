# 選択肢監査 (CHOICE_AUDIT)

ユーザーからの指摘: 「選択肢が無理やり防災に寄せてて臭い」。分析だけで、コードは変更していません。

## 集計
- 選択肢: 全452件 / シーン207件
- **B（説教・クイズ調）: 74件**（16%）
- A（自然な感情・人間関係の選択）: 378件
- 防災スコア（report.score）付きの選択肢: 158件（プラス127件、マイナス29件）
- 正解肢と誤答肢が並ぶ「正誤対立」シーン: 24件
- 章ごとのB件数: 0章 3/60、1章 8/36、2章 8/60、**3章 31/122**、**4章 20/107**、5章 4/67

判定はスクリプトによるヒューリスティックで、最終判断は目視が必要です（境界例あり）。基準は次の2つです。
- 教科書語（171、一時滞在施設、頭を守る、確認、ブレーカー、公式、低い姿勢 など）がラベルにあり、かつスコア付きまたは正誤対立
- 正誤対立シーンで、20字以上ある正解肢・誤答肢

## パターン
1. **ラベルが正解行動そのもの**（「頭を守る」「一時滞在施設にとどまる」「発信元と時刻を確かめ、公式の発表と見比べる」）
2. **誤答肢がわざと愚か**（「念のため転送する」「水を飲むのを控える」「全部運び出す」）。並んだ瞬間にどちらが正解か分かる
3. **台詞が知識の朗読**（「避難所は…一時滞在施設は…」「誰がいつ出した情報ですか。警察や区の発表を…」）
4. **伝言の文面まで模範解答**（171・web171の録音内容が選択肢に全文入っている）
5. **3択のうち1つだけ「正しい」**。残りの2つが感情の選択肢として弱い

## 書き換え方針
- 選択肢は「何を感じ、誰を優先するか」で書く。正しい手順はラベルに書かない
- どの選択肢も人として擁護できるものにする。誤答肢には、愛情・焦り・責任感といった筋の通った動機を持たせる
- 知識は**結果**（result文・次のシーン）と**他人の台詞**（宮内・小野寺・職員など）で見せる
- report.scoreは裏で評価し、エンディングの振り返りで初めて種明かしする
- 171などは「声を残す / 文字で残す」の選択に留め、伝言の文面は選択後に主人公が考える描写にする
- 正誤対立シーン（24件）は、どちらにも代償があるジレンマにする（例: 待つと安全だが、家族の不安が長引く）
