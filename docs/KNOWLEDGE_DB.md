### k_shindo_m 震度とマグニチュードは違う
- 分類: 地震の基礎 / レベル: 確立 / 状態: 出典確認済(専門家未監修)
- 出典: jma_shindo, jma_faq7

震度は「ある場所」の揺れの強さ、マグニチュードは「地震そのもの」の規模。同じ地震でも場所によって震度は変わる。本作の「お台場周辺で最大震度7」はゲーム上の架空の想定。

### k_eew 緊急地震速報が間に合わないこともある
- 分類: 地震の基礎 / レベル: 確立 / 状態: 出典確認済(専門家未監修)
- 出典: jma_eew

震源に近い場所では、速報より先に強い揺れが来ることがある。速報がなくても、揺れを感じたら身を守る行動を。

### k_drop まず低い姿勢・頭を守る・動かない
- 分類: 揺れの最中 / レベル: 確立 / 状態: 出典確認済(専門家未監修)
- 出典: kantei_jishin, tokyo_kitaku_ind

強い揺れの最中に走って移動すると、転倒や落下物・ガラスで負傷しやすい。丈夫な机の下や物が落ちてこない場所で、低い姿勢で頭を守る。

### k_window 窓・ガラス・照明・看板から離れる
- 分類: 揺れの最中 / レベル: 確立 / 状態: 出典確認済(専門家未監修)
- 出典: kantei_jishin

窓ガラスや外壁、看板、照明は割れたり落ちたりすることがある。屋内では窓から離れ、屋外では建物から離れた場所で頭を守る。

### k_outdoor 屋外では「落ちてくる・倒れてくる」ものから離れる
- 分類: 揺れの最中 / レベル: 確立 / 状態: 出典確認済(専門家未監修)
- 出典: kantei_jishin, tokyo_kitaku_ind

ブロック塀・自動販売機・電柱・ガラス張りの建物のそばを避ける。周囲に倒れてくる物がない場所で姿勢を低く。

### k_elevator エレベーターでは全階のボタンを押す
- 分類: 揺れの最中 / レベル: 確立 / 状態: 要監修
- 出典: tokyo_book

揺れを感じたら全ての階のボタンを押し、止まった階で降りる。閉じ込められたらインターホンで連絡して待つ。無理にこじ開けない。

### k_crowd 出口に殺到しない
- 分類: 揺れの直後 / レベル: 確立 / 状態: 要監修
- 出典: tokyo_kitaku

施設の誘導や放送を待ち、群集の中で走らない。将棋倒しの危険がある。

### k_fire_initial 初期消火には限界がある
- 分類: 火災 / レベル: 確立 / 状態: 要監修
- 出典: tokyo_book

小さな火なら消火器で消せる場合がある。炎が天井に届くほどになったら消火をやめて避難する、というのが一般的な目安。

### k_smoke 煙からは低い姿勢で離れる
- 分類: 火災 / レベル: 確立 / 状態: 要監修
- 出典: tokyo_book

煙は上にたまる。口と鼻を覆い、姿勢を低くして煙の来ない方向へ。

### k_tsunami 津波注意報・警報が出たら海岸から離れる
- 分類: 津波 / レベル: 確立 / 状態: 出典確認済(専門家未監修)
- 出典: jma_tsunami

注意報でも海に入ったり海岸に近づいたりしない。警報なら高台や頑丈な高い建物へ。様子を見に行かない。

### k_liquefaction 液状化：噴砂・段差・マンホールの浮き上がり
- 分類: 地盤 / レベル: 確立 / 状態: 要監修
- 出典: gsi_portal

埋立地などで地盤が液状化すると、砂や水が噴き出し、道路に段差や陥没が生じることがある。「埋立地だから必ず液状化する」わけではなく、場所ごとの地盤・対策で異なる。

### k_comm 電話はつながりにくくなる

- 出典: kantei_jishin

災害時は通話が集中し、電話やネットがつながりにくくなる。何度もかけ直すより、伝言サービスやメッセージを使う。

### k_171 災害用伝言ダイヤル171

### k_shelter_vs_place 避難場所と避難所の違い
