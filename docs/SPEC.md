# SPEC（実装仕様の要約）

元仕様：ユーザー提供の企画書（697行）。MVP項目（企画書 481–502行）の対応状況は COUNTS.md を参照。

- 舞台：お台場（実在地名＋架空施設。架空施設は名称に「（架空）」と明記）
- 地震：「首都直下地震」を想定した**架空のシナリオ**。お台場周辺の最大震度はゲーム上の仮定であり、マグニチュードとは別概念として図鑑で説明。
- 主人公プリセット：会社員（家族が江東区）／大学生（恋人が品川、祖母が世田谷）／親（子連れ、配偶者が品川の病院）
- 設定：発生時刻（平日昼・平日夜・休日）、備え（なし・少し・しっかり）、体調（ふつう・喘息）
- 状態：体力・スタミナ・水分・こころ・スマホ電池・負傷・持ち物・写真・知識・位置・人物の生死/信頼/所在
- 因果：危険への曝露ダメージ＝基礎値×（靴・頭部保護・マスク・夜間・疲労・脱水・既存の負傷）。時間経過で水分・電池が減り、手当てしていない傷は体力を削る。体力0で死亡（原因を記録）。
- 通信：発災〜3時間は電話不通、SMSは確率35%、171/web171は預け入れ可能。未送信メッセージは端末に残り、死亡時の「その後」に使われる。
- 情報：公式（ゲーム内架空情報）／施設／目撃／SNS を信頼度★で表示し、注記で検証ポイントを説明。
- 人物：18人。22の自律行動ルールが時刻と条件で発火（例：友人が一人で煙の中に戻ると数時間後に死亡）。
- 演出：揺れ（画面振動＋暗転、設定・prefers-reduced-motionで無効化）、音はWebAudioの低音のフェードイン（初期ミュート、急な大音量なし）。
- 広告：初期OFF。ONにしてもタイトルと章の区切りのみに枠。審査前のため中身なし。
- セーブ：localStorage、バージョン付き（v1）、移行関数、書き出し/読み込み。
- タイトル変更：「その日、東京が止まった。― AFTER THE SHOCK」→「ゆれのあと、きみへ。― ODAIBA AFTERLINES」（英題重複回避。日本語部分の同名作品は検索で見つからなかったが、英題と合わせて刷新）。
- 東京マグニチュード8.0 等の既存作品の人物・台詞・展開は使用していない。
